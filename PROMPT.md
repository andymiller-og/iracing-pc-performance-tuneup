# Single-prompt version

For harnesses that don't load `SKILL.md` skills. Start your agent in this folder (so it can run the scripts) and paste one of the two prompts below.

---

## Quick check (no load tests, about ten minutes)

You are checking my iRacing settings on this Windows PC for anything that is wrong regardless of hardware. Run `powershell -NoProfile -ExecutionPolicy Bypass -File` with `.\scripts\Test-Prerequisites.ps1`, `.\scripts\Get-SystemSnapshot.ps1` and `.\scripts\Find-IRacingConfig.ps1`. Read `references/hardware-triage.md` and use its low-hanging-fruit table. Ask me at most three things I haven't already told you (what I race and grid size; screens and monitor model; whether I put latency and steady frames, image quality, or a balance first). Web-search the current driver for my GPU and, for triples, my monitor's spec sheet. Reply with four short lists: **Wrong** (page and value, or file, section, key and value for ini-only settings, with one line of why), **Please confirm** (things the scripts can't see, such as VRR, with where to look), **Fine**, and **Can't tell without a capture**. Don't propose performance trades, don't change anything, and say which advice is general knowledge (AMD, VR).

---

## Full tune-up

You are helping me tune iRacing graphics and performance on this Windows PC, measure-first. Rules throughout: don't change the sim's ini files, the registry, drivers or Windows security settings yourself; tell me what to change, and do it only if I explicitly ask (ini edits only with the sim closed, after a `.bak` copy). Ask before installing anything. Web-search driver versions, vendor-app menus, monitor specs and VR headset specifics rather than quoting them from memory, and say what came from a search. Don't ask me anything I've already told you or the scripts can read. Match my level: if I know the Options pages, keep instructions terse.

1. **Preflight.** Run `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-Prerequisites.ps1`. If Intel PresentMon is missing and I have no CapFrameX/FrameView captures, give me the winget command and wait.
2. **Interview.** Run `scripts\Get-SystemSnapshot.ps1` and `scripts\Find-IRacingConfig.ps1` first so you can pre-fill what you detect (screens, VR headset, overlays). Ask the unanswered questions from `references/interview.md`, as clickable multiple-choice questions if you have a question tool (detected guess first, free-text answer always allowed), otherwise one compact numbered message. Save my answers as the driver profile in `Documents\iRacing-tuneup\tuneup-log.md`.
3. **Read the machine and the sim.** Run `scripts\Get-SystemSnapshot.ps1` and `scripts\Find-IRacingConfig.ps1`. Read `references/hardware-triage.md` and `references/settings-reference.md` and, for triples, `references/monitor-geometry.md`. Tell me what looks wrong, what is fine, and what you cannot determine (don't infer my PSU from my GPU). Every rig is different: treat costs in the references as directions, and let my captures decide.
4. **Baseline.** Design one repeatable offline AI race in my typical conditions (more scenarios only for conditions I race regularly), with my usual race-day software running. Start `scripts\Capture-PresentMon.ps1 -Label baseline-dry` while I'm at the desktop (it shows an elevation prompt), with a delay long enough to get in the car; give the tool call enough timeout. While I'm still on track, run `scripts\Read-IRacingSession.ps1`. Analyse with `scripts\Analyze-PresentMon.ps1 -Path <csv> -PowerLimitW <my GPU power limit> -TargetHz <my refresh or cap>` and read `references/diagnosis.md`. Tell me whether the limit is the CPU, the GPU (compute or memory), the frame cap, or balanced, with the numbers. Never use a replay as a driving benchmark.
5. **Plan batches** of 3–4 changes with page, setting, value, why and expected direction, ordered by the verdict, using `references/nvidia.md` (or `amd.md` / `vr.md`, saying they are from public sources and general knowledge). Test risky changes alone. Wait for my approval.
6. **For each batch:** give me the changes, then have me quit and relaunch the sim (one restart per batch: some settings only apply after a restart, and the settings file is written on exit). When I'm on the grid, verify the values saved with `Find-IRacingConfig.ps1` and start the capture of the same scenario in the same reply. Compare start windows, ask what it looked like, decide keep/revert per item, and log it.
7. **Report** using the short format in `references/report-template.md`, including what you deliberately did not change and why.
